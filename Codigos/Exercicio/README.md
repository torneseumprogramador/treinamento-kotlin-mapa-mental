## Como rodar

```bash
cd Codigos/Exercicio
./exec.sh 01-cadastro-cliente.kt
./exec.sh 02-pedido-loja.kt
./exec.sh 03-sessao-app.kt
```

## Regras (importante)

**Pode usar:** `val` / `var` / `const val`, tipos (`Int`, `Double`, `String`, `Boolean`, `Char`…), string template (`$`), conversão (`toInt()`, `toDouble()`, `toString()`), `String?`, `lateinit` (exercício 3), `readLine()`, `println`.

**Ainda não use:** `if`/`when`/`for`/`while`, listas, funções extras além do pedido, herança, coroutines.
